Social Media Addiction Prediction
The rapid growth of social media platforms has significantly influenced the lifestyle and behavior of students worldwide.
This study focuses on predicting social media addiction levels using a machine learning approach. 
The dataset includes various factors such as age, gender, academic level, daily social media usage hours, sleep duration, mental health score, and conflicts caused by social media use. 
Feature engineering techniques were applied to create meaningful variables such as usage intensity, sleep quality, and interaction features to improve model performance. 
Multiple regression models including Linear Regression, Ridge, Lasso, Random Forest, Gradient Boosting, and XGBoost were trained and evaluated to predict the addiction score.
Experimental results show that the Random Forest model achieved the best performance with high prediction accuracy and low error values.
The findings highlight the significant impact of mental health, sleep patterns, and daily usage hours on social media addiction. 
This research can help educators and policymakers develop strategies to monitor and reduce excessive social media use among students.
